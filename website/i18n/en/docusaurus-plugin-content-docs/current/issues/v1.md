# Frequently Asked Questions about the v1 version of the plug-in, no need to refer to it when using the latest version of the plug-in

## I wrote any value of `js` in `tailwindcss`, why didn’t it take effect?

See [issue#28](https://github.com/sonofmagic/weapp-tailwindcss-webpack-plugin/issues/28) for details

A: Because this plug-in mainly escapes `wxss`, `wxml` and `jsx`. `js` written in `string` is not escaped. If you have such a need, you can write:

```js
import { replaceJs } from 'weapp-tailwindcss-webpack-plugin/replace'
const cardsColor = reactive([
  replaceJs('bg-[#4268EA] shadow-indigo-100'),
  replaceJs('bg-[#123456] shadow-blue-100')
])
```

> You don’t have to worry about typing all the code in and the size will be too large. I only exposed 2 methods in 'weapp-tailwindcss-webpack-plugin/replace', and the code size is about 1k, in esm format.

## replaceJs Cross-end attention points

It is the `replaceJs` method in the FAQ. This method was originally designed for the mini program platform. If you have a code that needs to be compiled into the mini program and the `h5` platform at the same time, you can refer to the following package:

```js
// util.js
import { replaceJs } from 'weapp-tailwindcss-webpack-plugin/replace'
// How to write conditional compilation of uni-app
export function replaceClass(str) {
  // #ifdef H5
  return str
  // #endif
  return replaceJs(str)
}
// or environment variable judgment
export function replaceClass(str) {
// You need to customize it according to your target platform. Here are just some ideas.
  if(process.env.UNI_PLATFORM === 'h5'){
    return str
  }
  return replaceJs(str)
}

// then other.js
const cardsColor = reactive([
  replaceClass('bg-[#4268EA] shadow-indigo-100'),
  replaceClass('bg-[#123456] shadow-blue-100')
])
```

This will take effect on multiple terminals.
