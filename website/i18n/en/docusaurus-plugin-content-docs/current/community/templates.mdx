# 🔥Template for each framework

When you configure it incorrectly, you can also refer to the reference. The version with the 🔥 mark is the recommended version.

:::tip
If you encounter network problems and cannot log in to `Github`, you can use `Gitee`.

After logging into `Gitee`, click the plus sign in the upper right corner to see an import warehouse function. Then which template you want to use, right-click the link of the template below, click to copy the link address, and then paste the copied url into `Gitee` in the `Git Repository URL` import warehouse. After clicking OK to import, the warehouse will be synchronized in a few seconds and you can download it.
:::
