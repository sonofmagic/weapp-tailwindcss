`weapp-tailwindcss` comes with a `weapp-tw` command line tool, which is responsible for assisting in generating class name cache, collecting tokens and outputting compatibility prompts. `weapp-tailwindcss@5` has been taken over by the build runtime and Tailwind CSS processing has been taken over, `weapp-tw patch` is no longer a required step.

| Output Tailwind token and positioning information | |

## `patch` subcommand

:::tip There is no need to execute patch in the current version
If the project already uses `weapp-tailwindcss@5`, Tailwind CSS is taken over by the `WeappTailwindcss` plug-in or generator entry at build runtime, and there is no need to configure `package.json` in the business project's `postinstall: "weapp-tw patch"`.

`weapp-tw patch` is now a no-op command compatible with old scripts: it will prompt that execution is not required and will be skipped directly. Target records will no longer be written, and workspace batch patches will no longer be performed.
:::

### Function

- Compatible with residual `weapp-tw patch` / `weapp-tw install` calls in old projects or CI.
- Output a migration prompt to remind you to remove the `postinstall` hook.
-`--cwd`, `--clear-cache`, `--record-target`, and

### Common parameters

| Parameters | Default value | Meaning |
| --- | --- | --- |
| `--cwd <dir>` | None | Compatible with old script parameters and will not be used for patch parsing currently. |
| `--record-target` | None | Compatible with old script parameters, target records will not be generated currently. |
| `--clear-cache` | None | Compatible with old script parameters, cache will not be cleared currently. |
| `--workspace` | None | Compatible with old script parameters, workspace is not currently scanned. |

The running log is similar to:

```bash
$ pnpm --filter demo/native-ts weapp-tw patch
Tip: weapp-tailwindcss@5 has taken over Tailwind CSS processing by the build runtime, and weapp-tw patch no longer needs to be executed; please remove the postinstall hook in package.json.
Skipped: The current version does not require manual Tailwind CSS patching.
```

## `extract` subcommand

```bash
npx weapp-tw extract --css src/app.css --format lines
```

- `--css`: Tailwind entry CSS.
- `--output`: Specify the output file and write `.tw-patch/tw-class-cache.json` by default.
- `--format`: `json`/`lines`, with `--no-write` can only print to the terminal.
- `--cwd`: Specify the working directory for loading configuration and parsing dependencies.

The generated cache allows the builder to quickly read the `tailwindcss` compilation results and reduce the overhead of repeated startups.

## `tokens` subcommand

```bash
npx weapp-tw tokens --format grouped-json --group-key absolute
```

- `--format`: `json`, `lines` or `grouped-json`. The latter will be grouped by files to facilitate troubleshooting problems where `content` cannot match.
- `--group-key`: `relative` (default)/`absolute`, determines the basis for the output path.
- `--no-write`: Terminal preview, does not drop to disk; default is written to `.tw-patch/tw-token-report.json`.

The output data includes scanned files, class name tokens, occurrence positions (columns and columns), and a list of skipped files.

## `status` subcommand

```bash
npx weapp-tw status --cwd demo/native-ts
npx weapp-tw status --json
```

- `status` is now also compatible with the no-op command.
- `--cwd`: Compatible with old script parameters.
- `--json`: Output `{ "required": false, "status": "unnecessary" }` style report for easy reading by CI or script.

## Quick troubleshooting guide

1. **Remove the patch in the installation life cycle first**: delete `postinstall: "weapp-tw patch"`.
2. **Class name is missing**: Use `weapp-tw extract` or `weapp-tw tokens --no-write` to assist in locating which piece of code is not included in Tailwind `@source`.
3. **Any value does not meet expectations**: Prioritize checking whether the entry CSS, `@source`, `cssEntries` and build plug-ins are effective.

With these commands, you can observe the Tailwind scan results more intuitively and reduce the cost of positioning such as "the class name is not generated".
