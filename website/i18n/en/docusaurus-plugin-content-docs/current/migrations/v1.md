# Migrate from v1 to v2

In the `2.x` version, all previously used `webpack` plug-ins can be replaced with `WeappTailwindcss` plug-ins, but there are some minor changes in the export of the `vite` plug-in:

`1.x`:

```js
import vwt from 'weapp-tailwindcss-webpack-plugin/vite';
```

`2.x`:

```js
// WeappTailwindcss is the new plug-in
import { WeappTailwindcss } from 'weapp-tailwindcss-webpack-plugin/vite';
```

In addition, the new `WeappTailwindcss` can be directly introduced from `weapp-tailwindcss-webpack-plugin`. At the same time, in the new `WeappTailwindcss`, all the previous configuration items have been inherited, and you only need to use it to directly replace the original plug-in.

Also don’t forget to put:

```json
 "scripts": {
+  "postinstall": "weapp-tw patch"
 }
```

Add it to your `package.json`, then clear the original packaging cache and repackage and run.
