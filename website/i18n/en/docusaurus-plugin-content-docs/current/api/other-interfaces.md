The following interfaces are used to supplement configuration or runtime capabilities. This page only provides an index.

- [ApplyOptions](./interfaces/ApplyOptions.md) - Tailwind runtime behavior configuration.
- [CacheOptions](./interfaces/CacheOptions.md) - Tailwind class name cache configuration.
- [ExtractOptions](./interfaces/ExtractOptions.md) - Output configuration of class name extraction results.
- [TailwindCssOptions](./interfaces/TailwindCssOptions.md) - Runtime configuration by Tailwind version.
- [TailwindCssRuntimeOptions](./interfaces/TailwindCssRuntimeOptions.md) - Tailwind CSS runtime root configuration.
- [TailwindV4Options](./interfaces/TailwindV4Options.md) - Tailwind CSS v4 extraction configuration.
- [WeappTailwindcssGenerateOptions](./interfaces/WeappTailwindcssGenerateOptions.md) - Call configuration of weapp-tailwindcss generator.
- [WeappTailwindcssGenerateResult](./interfaces/WeappTailwindcssGenerateResult.md) - The output result of the weapp-tailwindcss generator.
- [WeappTailwindcssGenerator](./interfaces/WeappTailwindcssGenerator.md) - weapp-tailwindcss unified generator instance.
- [WeappTailwindcssGeneratorTarget](./interfaces/WeappTailwindcssGeneratorTarget.md)
- [WeappTailwindcssPostcssPluginOptions](./interfaces/WeappTailwindcssPostcssPluginOptions.md) - `weapp-tailwindcss` PostCSS plugin configuration.
- [WeappTailwindcssStyleInjectorOptions](./interfaces/WeappTailwindcssStyleInjectorOptions.md)
