## Important restrictions

- The native App text needs to be placed in the `<text>` element, and the text style must also be directly applied to `<text>`
- `uvue` native App does not support `gap`, `gap-x-*`, `gap-y-*`
- `space-x-*` and `space-y-*` should not be used as layout schemes in `uni-app x`
- It is recommended to directly write `mt-*` /
- When a CSS compatibility warning appears in the HBuilderX console, the style will be adjusted according to the target platform restrictions first.
