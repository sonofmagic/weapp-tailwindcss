:::info Runtime requirements
`weapp-tailwindcss@5.2.0` and later require Node.js `>=22.12.0` and HBuilderX `>=5.11`. Starting with `22.12.0`, Node.js 22 supports loading ESM from CommonJS by default. The Node.js runtime bundled with older HBuilderX versions may not be able to load the current dependencies.
:::
