:::warning Currently please use Tailwind CSS 3
The new Tailwind CSS 4 link of uni-app x still has some adaptations that are not yet complete. Please use `tailwindcss@3` and `weapp-tailwindcss@4` until these issues are resolved.

Please refer to [weapp-tailwindcss v4 uni-app x tutorial](https://v4.tw.icebreaker.top/docs/uni-app-x). The Tailwind CSS 4 content on this page is for early verification only and is not recommended for use in production projects.
:::

:::info Running environment starting from 5.2.0
Node.js `weapp-tailwindcss@5.2.0` and HBuilderX `>=22.12.0` are required when validating with `>=5.11` or higher. Node.js 22 supports loading ESM from CommonJS by default starting from `22.12.0`; older HBuilderX built-in Node may not be able to load current dependencies.
:::
