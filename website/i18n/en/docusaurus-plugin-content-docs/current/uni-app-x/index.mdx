## Development suggestions

- Recommended editor collaboration: use VS Code to write code, and use HBuilderX to run and build
- Android-side debugging is preferred: CSS compatibility is generally Web > Mini Program > App (Android/iOS/Hongmeng). First use the Android emulator to open the path, the cross-end cost is the lowest
- Note on component semantics: Native App-side text must be placed in the `<text>` tag, and the text style must be directly applied to this element
- Progressive enhancement: If some styles are limited on the App side, priority is given to ensuring the Android side experience, and then conditional compilation and adaptation to mini programs/Web are done as needed.

## Layout capability boundaries

- `uvue` native App does not support `gap`, `gap-x-*`, `gap-y-*`, including all grid gap and flex gap scenarios
- `space-x-*` and `space-y-*` are no longer supported in `uni-app x`, please do not use them
- When it is necessary to securely cross terminals, the priority is to explicitly write `mt-*` /

## Why is it recommended to use Android first?

1) The style constraints on the native side are stricter. For example, text must use `<text>`, and many CSS features are still being completed.
2) If your page has no alarms and is displayed correctly on the Android side, the mental burden of migrating to mini programs and the Web will be much lighter.
3) The debugging threshold for iOS/Hongmeng is higher (device/system requirements), and it is more pragmatic for most teams to prioritize Android.

## FAQ

### VS Code highlights and jumps to uvue/uts

Install the official language service plug-in:
- ID: dcloud-ide.hbuilderx-language-services  
- Description: Supports prompts, suspension, go to definition, search for references, verification, etc. of uni-app x project
- Link: https://marketplace.visualstudio.com/items?itemName=dcloud-ide.hbuilderx-language-services

### Tailwind CSS Smart Tips

VS Code does not natively recognize `uvue/uts`. It is recommended to add language mapping to the Tailwind extension. Create `.vscode/settings.json` in the project root directory:

```json title=".vscode/settings.json"
{
  "tailwindCSS.includeLanguages": {
    "uvue": "html",
    "uts": "javascript"
  }
}
```

### Operation mode

The running and building of uni-app x is still based on HBuilderX. When you need command line automation, you can use HBuilderX CLI; the local E2E of this warehouse runs Web, applet and App targets through `hbuilderx launch`.
