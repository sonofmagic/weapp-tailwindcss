# New features in version 2.x

This version adds `WeappTailwindcss`
and `WeappTailwindcss` the Vite plugin.

They automatically recognize and accurately handle all `tailwindcss` tool classes. This means it can handle static or dynamic `class` in all files simultaneously.

Compared with the `v1` version, which only has the ability to process `wxss`, The `wxml` plug-in has the ability to accurately convert `class`/`v2`, which greatly improves the development experience of dynamic template frameworks such as `js`.

## Introduction to new plug-ins

`WeappTailwindcss` is a core plug-in. All frameworks packaged with `webpack` can use it. You only need to pass in the `appType` configuration items:

Currently, this solution only supports versions above `tailwindcss v3.2.2` and `webpack5`. At the same time, this solution depends on `monkey patch`, so you should put

```json
 "scripts": {
+  "postinstall": "weapp-tw patch"
 }
```

Add your `package.json`. Of course, after installing or updating `tailwindcss`, the effect of manually executing `npx weapp-tw patch` is the same. Seeing `patch .... successfully` indicates success.

`WeappTailwindcss` is a dedicated plug-in for `vite`. The configuration items and usage methods are also consistent with the above.
