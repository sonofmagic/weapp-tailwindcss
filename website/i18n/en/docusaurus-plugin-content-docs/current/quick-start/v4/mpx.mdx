# Mpx

:::tip
Mainline access documentation has been merged into [Mpx](/docs/quick-start/frameworks/mpx). This page is reserved for legacy links and Tailwind CSS 4-specific troubleshooting.
:::

## Install

```bash npm2yarn
npm install -D tailwindcss weapp-tailwindcss
```

## Configuration

Change `mpx.config.js` Register `weapp-tailwindcss`

```js title="mpx.config.js"
const { defineConfig } = require('@vue/cli-service')
const { WeappTailwindcss } = require('weapp-tailwindcss/webpack')
const path = require('node:path')
module.exports = defineConfig({
  outputDir: `dist/${process.env.MPX_CURRENT_TARGET_MODE}`,
  pluginOptions: {
    mpx: {
      plugin: {
        postcssInlineConfig: {
          ignoreConfigFile: true,
          plugins: []
        },
        srcMode: 'wx',
        hackResolveBuildDependencies: ({ files, resolveDependencies }) => {
          const path = require('path')
          const packageJSONPath = path.resolve('package.json')
          if (files.has(packageJSONPath)) files.delete(packageJSONPath)
          if (resolveDependencies.files.has(packageJSONPath)) {
            resolveDependencies.files.delete(packageJSONPath)
          }
        }
      },
      loader: {}
    }
  },
  configureWebpack(config) {
// Added code goes here
    // highlight-start
    config.plugins.push(
      new WeappTailwindcss({
        appType: 'mpx',
        cssOptions: {
          rem2rpx: true,
        },
        cssEntries: [
// Tailwind CSS entry file absolute path
          path.resolve(__dirname, './src/app.css'),
        ],
      })
    )
    // highlight-end
  }
})
```

> tailwindcss@4 must configure `cssEntries` and use absolute paths, otherwise the class names generated by `tailwindcss` will not participate in translation.
> The CSS generation of Mpx is also taken over by `WeappTailwindcss`, do not register the Tailwind PostCSS generation plug-in again.
> The registration target here must also be a pure `css` entry file. Do not put `tailwindcss@4` into the `scss` / `less` / `sass` entry, otherwise the style generation and `weapp-tailwindcss` translation may fail.

## Add style

Introducing Tailwind CSS in `src/app.css`:

```css title="src/app.css"
@import "tailwindcss";
@source "../src";
```

<CssImportReminder />

> Tailwind CSS 4.x uses CSS-first entry. `@source "../src";` is used to tell Tailwind to scan the Mpx source directory.

Then in the project directory, in the mini program global `app.mpx`, introduce the file through `@import`:

```html title="app.mpx"
<style lang="css">
@import "./app.css";
</style>
```


After changing the configuration, just start it
