# Taro vite

:::tip
Mainline access documentation has been merged into [Taro](/docs/quick-start/frameworks/taro). This page is reserved for legacy links and Tailwind CSS 4-specific troubleshooting.
:::

:::danger
`Taro Vite` is currently unstable, has many known bugs, and has an older dependency chain version. It is not recommended to use it in new projects.

If there are no strong dependencies, give priority to more stable solutions such as `Taro Webpack`, `uni-app`, and `weapp-vite`.
:::

## Install

```bash npm2yarn
npm install -D tailwindcss weapp-tailwindcss
```

> In `Taro Vite`, Tailwind CSS generation is taken over by `weapp-tailwindcss`, and there is no need to register `@tailwindcss/vite` or `@tailwindcss/postcss` additionally.

## Configuration

```js title="config/index.ts"
import path from 'node:path'
import { WeappTailwindcss } from 'weapp-tailwindcss/vite'

const projectRoot = path.resolve(__dirname, '..')

{
  compiler: {
    type: 'vite',
    vitePlugins: [
      WeappTailwindcss({
        cssOptions: {
          rem2rpx: true,
        },
        tailwindcssBasedir: projectRoot,
        cssEntries: [
          path.resolve(projectRoot, 'src/app.css'),
        ],
      }),
    ]
  },
}
```

> Tailwind CSS 4 projects should explicitly configure `cssEntries` and use the absolute path resolved from the project root to point to the pure `.css` entry.
> This is Tailwind CSS 4: `cssEntries` Please point to pure `.css` files, do not point to `scss` / `less` / `sass`. Business Sass/Less can continue to be used, but it is recommended that the `@import "tailwindcss"` entry of Tailwind 4 be placed in a separate CSS file.

`cssEntries` is only responsible for allowing `WeappTailwindcss` to stably read the Tailwind CSS entry. The entry CSS still has to be actually introduced through the Taro entry. Please write multiple entries or sub-entries into the array:

```js
import path from 'node:path'

const projectRoot = path.resolve(__dirname, '..')

WeappTailwindcss({
  cssOptions: {
    rem2rpx: true,
  },
  tailwindcssBasedir: projectRoot,
  cssEntries: [
    path.resolve(projectRoot, 'src/app.css'),
  ],
})
```

## Add style

In `src/app.css` under the project directory, add the following content:

```css title="src/app.css"
@import "tailwindcss" source(none);
@source "../src";
```

> The `Taro Vite` scene also uses the CSS-first entry of Tailwind CSS 4. Mini program target CSS is output by `WeappTailwindcss`, and there is no need to add the official Tailwind Vite or PostCSS plug-in to the build.

The default Tailwind entry here is at `src/app.css`. `@source "../src";` will scan the entire source code directory, including pages, components, and your own newly added business directories.

After changing the configuration, run the startup project directly and import the project into the WeChat developer tool to see the effect.

> Once again: The content on this page is more suitable as a historical access description and troubleshooting reference. It is not recommended to use `Taro Vite` as the new default technology selection.
