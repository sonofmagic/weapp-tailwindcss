## Install

```bash npm2yarn
npm install -D tailwindcss weapp-tailwindcss
```

## Configuration

### Create `vue.config.js`

```js title="vue.config.js"
const { WeappTailwindcss } = require('weapp-tailwindcss/webpack')
const path = require('node:path')
/**
 * @type {import('@vue/cli-service').ProjectOptions}
 */
const config = {
  // some option...
  configureWebpack: (config) => {
    config.plugins.push(
      new WeappTailwindcss({
        cssOptions: {
          rem2rpx: true,
        },
        cssEntries: [
// Tailwind CSS entry file absolute path
          path.resolve(__dirname, './src/app.css'),
        ],
      })
    )
  }
  // other option...
}

module.exports = config
```

> tailwindcss@4 must configure `cssEntries` and use absolute paths, otherwise the class names generated by `tailwindcss` will not participate in translation.

## PostCSS configuration

`weapp-tailwindcss@5` is generated by the Webpack plug-in by default and takes over the Tailwind CSS style generation. There is no need to register `postcss.config.js` in `@tailwindcss/postcss`. If this stock project already has PostCSS configuration, only keep non-Tailwind plug-ins such as `postcss-import`, `autoprefixer`, and `@dcloudio/vue-cli-plugin-uni/packages/postcss`.
