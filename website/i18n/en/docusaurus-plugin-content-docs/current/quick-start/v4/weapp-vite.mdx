# Weapp-vite

:::tip
Mainline access documents have been merged into [native applet / weapp-vite](/docs/quick-start/native/install). This page is reserved for legacy links and Tailwind CSS 4-specific troubleshooting.
:::

## Install

```bash npm2yarn
npm install -D tailwindcss weapp-tailwindcss
```

## Configuration

Change `vite.config.ts` Register `weapp-tailwindcss`

```js title="vite.config.ts"
import { dirname, resolve } from 'node:path'
import { fileURLToPath } from 'node:url'
import { WeappTailwindcss } from 'weapp-tailwindcss/vite'
import { defineConfig } from 'weapp-vite/config'

const projectRoot = dirname(fileURLToPath(import.meta.url))

export default defineConfig({
  plugins: [
    WeappTailwindcss({
      cssEntries: [
        resolve(projectRoot, 'app.css'),
      ],
      cssOptions: {
        rem2rpx: true,
      },
    }),
  ],
})
```

`weapp-tailwindcss@5` enables generation mode by default, no need to register `@tailwindcss/vite` or `@tailwindcss/postcss`. If the project already has `postcss.config.js`, you can continue to keep the business's own PostCSS plug-in, but please remove the Tailwind official generated plug-in.
Tailwind CSS 4 projects should explicitly configure `cssEntries` to allow `WeappTailwindcss` to stably read Tailwind CSS entries such as `app.css`. `cssEntries` is only responsible for portal identification, and the portal CSS still has to be actually introduced through the project portal.

## Add style

In the project directory, add the following content to the global `app.css` of the mini program:

```css title="app.css"
@import "tailwindcss";
@source "./src/**/*.{wxml,js,ts,vue}";
@source "./app.{js,ts,json}";
@source not "./dist";
```
