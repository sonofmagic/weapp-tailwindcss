## 1. Installation

```bash npm2yarn
#Initialize package.json
npm init
# Installation package
npm install -D tailwindcss weapp-tailwindcss
```

## 2. Add `vite.config.ts`

```ts title="vite.config.ts"
import { defineConfig } from "vite";
import uni from "@dcloudio/vite-plugin-uni";
import { WeappTailwindcss } from 'weapp-tailwindcss/vite'
import { dirname, resolve } from 'node:path'
import { fileURLToPath } from 'node:url'

const projectRoot = dirname(fileURLToPath(import.meta.url))

export default defineConfig({
  plugins: [
    uni(),
    WeappTailwindcss({
      cssOptions: {
        rem2rpx: true,
      },
      tailwindcssBasedir: projectRoot,
      cssEntries: [
// Tailwind CSS entry file absolute path
        resolve(projectRoot, 'src/app.css'),
      ],
    }),
  ],
});
```

> tailwindcss@4 must configure `cssEntries` and use absolute paths, otherwise `weapp-tailwindcss` cannot stably locate the CSS entry.

Write an observable tool class on the page, such as `bg-[#123456] text-[#654321]`, and then run it in the WeChat developer tools to check the effect.

## Layout restrictions

- Do not use `uni-app x`, `gap`, `gap-x-*` in `gap-y-*`
- Do not use `uni-app x`, `space-x-*` in `space-y-*`
- When spacing is required, please write `mt-*` / `ml-*` directly to the sub-item, or encapsulate the spacing component of the fixed structure
