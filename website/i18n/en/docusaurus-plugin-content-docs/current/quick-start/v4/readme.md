# Tailwind CSS 4 old entry has been migrated

`/docs/quick-start/v4` is no longer a quick start entry, and it no longer indicates that Tailwind CSS 4 is an optional or experimental additional access method. The current document uses the Tailwind CSS 4 generation mode by default; CSS-first, `@source`, `@apply`, `@layer`, IntelliSense and multi-terminal supplementary instructions have been moved to the Tailwind topic.

Please go to [Tailwind CSS 4 Default Mode Reference](/docs/tailwindcss/v4-reference).

If this is your first time accessing the project, please start with [Installation Dependencies] (/docs/quick-start/install) and then enter the corresponding framework registration page.
