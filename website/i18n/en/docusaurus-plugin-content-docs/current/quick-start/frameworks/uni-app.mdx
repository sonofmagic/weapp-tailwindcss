# uni-app CLI Vue2 Webpack

:::caution
This `uni-app cli vue2 webpack` route is no longer recommended, and the corresponding classic demo in the warehouse has been removed.

For new projects, please use [uni-app cli vue3 vite](/docs/quick-start/frameworks/uni-app-vite) directly.
:::

<ExternalClassesReminder framework="uni-app" />

:::warning
This article is only retained as an archive description of existing projects and is no longer a recommended access method.
:::

```js title="vue.config.js"
const path = require('node:path')
const { WeappTailwindcss } = require('weapp-tailwindcss/webpack')
/**
 * @type {import('@vue/cli-service').ProjectOptions}
 */
const config = {
  // some option...
  // highlight-start
  configureWebpack: (config) => {
    config.plugins.push(
      new WeappTailwindcss({
        cssOptions: {
          rem2rpx: true,
        },
        cssEntries: [
          path.resolve(__dirname, 'src/app.css'),
        ],
      })
    )
  }
  // highlight-end
  // other option...
}

module.exports = config
```

`src/app.css` uses the Tailwind CSS 4 portal. The current documentation only maintains Tailwind CSS 4 access instructions.

```css title="src/app.css"
@import "tailwindcss";
@source "./**/*.{html,js,ts,jsx,tsx,vue}";
@source not "../dist";
@source not "../node_modules";
@source not "../unpackage";
```

The scanning range is written in `@source` in the CSS entry. Do not register the Tailwind official build plug-in in PostCSS in build mode.

`cssEntries` is only responsible for entry identification. The existing projects must still be in the global style of `src/App.vue`. Otherwise, the generated CSS will not enter the Webpack module diagram.
