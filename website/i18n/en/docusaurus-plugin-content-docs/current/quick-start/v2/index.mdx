# Tailwindcss 2.x

Currently, some users already have `webpack 4`, `postcss 7.x` and cannot upgrade due to their existing projects, but they still want to use `tailwindcss`,

So I wrote this document as a reference. In the case of the existing version, it is not recommended for any new projects.

## Install

In this condition, only the `tailwindcss 2.x` version can be used.

Refer to the installation method in https://v2.tailwindcss.com/docs/installation#post-css-7-compatibility-build

After installation, be sure to turn on `jit` mode, https://github.com/icebreaker-trash/uni-app-vue2-tailwind-hbuilder-template/blob/master/tailwind.config.js

For more details, see the template code below.

## vue2 hbuilderx reference template

Note that it must be set in the development environment

```js
process.env.TAILWIND_MODE = "watch"
```

to perform normal hot updates

Template source code address:

https://github.com/icebreaker-template/uni-app-vue2-tailwind-hbuilder-template
